# 实验报告：抗伪造防御成功率（2026-09-08）

## 1. 实验环境
- Windows 本地 CPU（Python 3 / numpy），单线程脚本，全程 `seed=42`；
- RSA 基线模数 1024-bit；LWE 参数按《技术交底书》：n=128, q=12289, σ=2, V=8。

## 2. 威胁模型与攻击预算
- 统一口径：**自适应选择消息预言机 + 有界查询预算**。攻击者可索取若干
  历史样本，但拿不到私钥 s，目标是对一笔“新交易”伪造通过验证的凭证；
- LWE：每轮最多 M=8 个历史样本，最小二乘 + 就近舍入到 {-1,0,1} 恢复 s；
- RSA raw（教科书，无填充）：每轮 2 次选择消息签名，利用乘法同态存在性伪造；
- RSA + SHA-256（类 FDH 对照）：尝试同种乘法伪造（被哈希破坏）。

## 3. 结果（N=10000 / 方案）
| 方案 | 伪造成功 | 防护成功率 |
| --- | --- | --- |
| LWE（本方案） | 0 / 10000 | 100.00% |
| RSA raw（教科书） | 10000 / 10000 | 0.00% |
| RSA + SHA-256（对照） | 0 / 10000 | 100.00% |

总耗时约 360s（本地 CPU）。

## 4. 辅助测量（“数形结合”）
- 篡改检测率 **100.0%**、盲猜凭证拒绝率 **100.0%**（1500 样本），
  合法凭证误拒率 **0.0%**（验证阈值 V=8 > 噪声截断 ±6）；
- 攻击预算扫描：M ∈ {1,2,4,8,16,32,64,96}，伪造成功率均为 **0%**（每点 40 次）；
- 延迟基准（150 次均值，ms）：

| 方案 | 签发/签名 | 验证 |
| --- | --- | --- |
| LWE (n=128) | 2.08 | 0.085 |
| RSA-1024 | 2.78 | 0.038 |
| RSA-2048 | 18.82 | 0.130 |

## 6. 结论与边界
- 在本文明确定义的攻击模型下：LWE 方案对伪造**实测免疫**（0/10000），
  教科书 RSA 被全部伪造（10000/10000）；
- “RSA + SHA-256”在该伪造攻击下安全，但**并未模拟 Shor/因数分解攻击**，
  因此本实验是“给定攻击模型的量化对照”，不是形式化安全证明；
- 尚未实现 LLL/BKZ 格基规约攻击与真实 RSA-PSS 对照；生产级参数
  （n/q/σ 与错误率、量化安全水平）需独立分析后另行补充。
