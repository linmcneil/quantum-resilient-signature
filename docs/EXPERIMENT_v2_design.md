# v2 实验设计方案（提案版 v0.1，2026-09-08）

> 配套文档：docs/LITERATURE_REVIEW.md（前沿调研笔记）。本文件给出算法改进点与实验设计，
> 与 2025–2026 学界口径对齐，目标产物可用于 CV / 结题 / 答辩，全部本地 CPU 可复现。

## 0. 目标

把项目做成“口径诚实、可复现、有可辩护创新点”的抗量子认证/签名工程实验：
一条与 NIST 标准同口径的 benchmark 主线 + 一组安全-性能曲线。

## 1. 语义修正（先立正再谈创新）

专利原方案 `b = A·s + e (mod q)` 的验签需要私钥 s，属**对称语义**（MAC/认证标签），
不是数字签名，不能与 RSA/ML-DSA 直接同层比较。v2 明确两条线：

- **Track A · 轻量认证标签（LWE-MAC）**：面向“交易广播 + 指定接收方离线校验”场景；
  与 HMAC/类 DSS 语义的对象比较，不和公开签名方案比“谁防伪造”。
- **Track B · 公开可验证 LWE 签名（推荐主线）**：按 Lyubashevsky
  *Fiat–Shamir with Aborts* 风格构造公开验证签名原型，与 RSA-PSS / ML-DSA 同层对比。

删除 v1 的“LWE 100% vs RSA 0%”叙事与教科书 RSA raw 对照。

## 2. 算法改进：创新点候选（按可辩护性分级）

### I1（主推 · 方法学闭环）：参数实例化 + 交叉验证方法学
输入目标比特安全 λ → 用 lattice-estimator 扫描 (n, q, σ, 重试预算、拒绝阈值)
→ 输出参数表（含估计 bit 成本与最优 BKZ β）→ 在**缩尺小维度**上实现
LLL/BKZ + Babai 攻击，实测“密钥恢复/伪造成功率 vs 参数”的相变点
→ 画“理论估计 vs 实测相变”对照图。
价值：安全参数不再“拍脑袋”，两层证据互相印证；国内大创少有人做完整闭环，好讲、好答辩。

### I2（交易场景微创新 · 需标注安全边界）：消息派生矩阵
类似 ML-DSA 用随机 seed 展开矩阵 A，但把 seed 换成 `SHA-256(tx)`（“一事一密”的专利思想）
→ 公钥/签名中无需再传矩阵种子 → 每笔交易带宽更小。
**诚实边界**：A 随被签消息变化，攻击者可挑消息从而挑 A，需要额外归约论证；
本项目以“工程可行性评估 + 未来工作”呈现，不宣称已获正式安全证明。

### I3（数据面 · 可直接发开源）：可复现评测数据集
输出统一 schema 的 JSON/CSV：尺寸、耗时分布、拒绝次数分布、区块膨胀系数，
对齐 2025–2026 区块链 PQC 综述的报告口径（如 MDPI Technologies 14(6):367）。

## 3. 实验设计（四大块）

### E1 正确性与误拒阈值曲线
往返验证成功率；篡改检测率；**误拒率 vs 阈值 V 的 trade-off 曲线**（不是单点 0%/100%）。
画法：x = V，双 y = 合法样本误拒率 / 篡改样本通过率，标出理论噪声界 ±B。

### E2 原型尺寸与耗时对照（对标 ePrint 2026/1333 方法论）
方案：RSA-3072-PSS（标准库）、ML-DSA-44 与 FN-DSA-512（库可得则实测，否则尺寸表引用
官方规格值并注明；FN-DSA-512 按 FALCON v1.2/FN-DSA 草案值，FIPS 206 尚未发布）、本方案 Track A / Track B（estimator 定参后）。
指标：pk / sk / sig 字节数；keygen / sign / verify 耗时；
**每方案 ≥1000 次**，报告 median / p50 / p90 / p99 / max；
对含拒绝采样的方案额外报告**单次签名拒绝次数分布**（长尾/WCET）。
画法：箱线图 + 累计分布(ECDF) 双面板。

### E3 安全边界曲线（缩尺小维度攻击）
LLL/BKZ + Babai：密钥恢复成功概率 vs (n, σ, 历史样本数 M)；
伪造成功概率 vs 噪声尺度与阈值。
画法：三条**相变曲线**（x = 参数，y = 成功率，标注 log2 攻击成本次轴）——
这是“数形结合”讲安全性的最好素材。

### E4 区块链场景（对标综述报告口径）
合成 n 笔交易的区块 → 输出：区块膨胀系数、单区块验签总 CPU 耗时、TPS 估算，
与 ECDSA / ML-DSA 对照。画法：双轴图（交易数 vs 区块字节数 / 验签耗时）+ 汇总表。
